## API access

### JSON-RPC

Sui's JSON-RPC interface is the current standard for querying chain state and submitting transactions. Triton provides access on both mainnet and testnet. Note that Mysten Labs has announced JSON-RPC deprecation for 2026 — gRPC will replace it as the primary interface.

### gRPC (beta)

Triton provides low-latency gRPC endpoints for Sui mainnet and testnet. gRPC offers persistent streaming connections for subscribing to object updates, transaction commits, and event logs. This interface is currently in beta and will become the primary API as JSON-RPC is retired.

<Tip>
  gRPC is the recommended interface for indexers, explorers, and reactive frontends that depend on real-time data. Subscribe to object updates and transaction events with minimal delay.
</Tip>

### GraphQL (coming Q1–Q2 2026)

Sui is rolling out a GraphQL alpha backed by an indexing layer. Triton will support the GraphQL API as it becomes available, giving you a structured query surface for complex object and transaction lookups.

## Walrus decentralized storage

[Walrus](https://walrus.xyz/) is Sui's decentralized, scalable, distributed, and fault-tolerant storage layer, optimized for storing large binary blobs. Sui is used for coordination between Walrus nodes.

Triton hosts all three Walrus components:

## Seal

Seal is Sui's content-addressed data model layer. Triton provides:

- **Open server** on Testnet — available for early indexing experiments, proofs, and developer workflows that need flexible, verifiable storage access.
- **Permissioned server** on Mainnet and Testnet — enterprise-grade endpoints with controlled access and higher throughput for production applications that require trusted, authenticated storage operations.

## Infrastructure

Triton deploys dedicated nodes across North America, Europe, and APAC, with built-in load balancing and regional failover. Traffic is routed to the closest healthy region and balanced across available nodes automatically — no manual intervention required when individual servers go offline.
