---
title: "getSlot"
description: "Returns the slot that the validator is currently processing."
api: 'POST https://api.mainnet-beta.solana.com'
---

Returns the slot the cluster is currently processing. Slots are Solana's unit of time -- the network produces a new slot roughly every 400ms. Use this to track liveness or to anchor recent events.

## Request body

<ParamField body="jsonrpc" type="string" required>
  Always `"2.0"`.
</ParamField>

<ParamField body="id" type="integer" required>
  An identifier you choose; the server echoes it back.
</ParamField>

<ParamField body="method" type="string" required>
  Always `"getSlot"`.
</ParamField>

<ParamField body="params" type="array">
  Optional `[config]` object:
  - `config.commitment` (string, optional) -- one of `"processed"`, `"confirmed"`, `"finalized"`. Defaults to `"finalized"`.
</ParamField>

## Response

<ResponseField name="result" type="integer">
  The current slot number at the requested commitment level.
</ResponseField>

## Example

<RequestExample>

```json Request
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getSlot"
}
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "jsonrpc": "2.0",
  "result": 280123456,
  "id": 1
}
```

</ResponseExample>
