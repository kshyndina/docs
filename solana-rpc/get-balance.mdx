---
title: "getBalance"
description: "Returns the lamport balance of the account at the provided pubkey. 1 SOL = 10⁹ lamports."
api: 'POST https://api.mainnet-beta.solana.com'
authMethod: "none"
---

Returns the lamport balance of an account at a given Solana address (pubkey). Use this to check how much SOL an account holds. 1 SOL = 10⁹ lamports.

## Request body

JSON-RPC 2.0 envelope. The `params` array takes the base58 pubkey, then an optional config object.

<ParamField body="jsonrpc" type="string" required>
  Always `"2.0"`.
</ParamField>

<ParamField body="id" type="integer" required>
  An identifier you choose; the server echoes it back.
</ParamField>

<ParamField body="method" type="string" required>
  Always `"getBalance"`.
</ParamField>

<ParamField body="params" type="array" required>
  `[pubkey, config?]` where `pubkey` is a base58-encoded account address and `config` is optional.
  - `pubkey` (string, required) -- the base58 account address
  - `config.commitment` (string, optional) -- one of `"processed"`, `"confirmed"`, `"finalized"`. Defaults to `"finalized"`.
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Echoes the request id.
</ResponseField>

<ResponseField name="result" type="object">
  - `context.slot` (integer) -- the slot the result was retrieved at
  - `value` (integer) -- the balance in lamports
</ResponseField>


</RequestExample>
