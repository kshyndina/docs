This section is a live playground for Solana's standard JSON-RPC methods. Every page in this group lets you build a real request, hit **Try it**, and see the actual response from a Solana node -- no terminal, no copy-paste.

## How it works

The playground points at the public Solana mainnet endpoint:

```
https://api.mainnet-beta.solana.com
```

Solana RPC uses **JSON-RPC 2.0** over HTTP POST. Every request shares the same envelope:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "<the method name>",
  "params": [ /* method-specific params */ ]
}
```

Each page in this group is one method. Edit the body, hit Send, get a real response.

## Public mainnet vs your Triton endpoint

The pages here demo the public Solana mainnet endpoint, which is rate-limited and shared. To use your **Triton-provided endpoint** with much higher limits and SLA:

1. Sign up at the [Customer Portal](https://customers.triton.one)
2. Replace `https://api.mainnet-beta.solana.com` with your endpoint URL (e.g. `https://your-app.mainnet.rpcpool.com`)
3. For backend traffic, append your secret token: `https://your-app.mainnet.rpcpool.com/your-secret-token`

See [getting started](/getting-started) for the full onboarding flow.
