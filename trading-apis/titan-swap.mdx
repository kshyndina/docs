Titan Swap API gives you a live stream of the best swap quotes available on Solana, updating continuously over a WebSocket connection. Rather than polling a REST endpoint and waiting for each response, your application receives new quotes as they arrive — enabling price displays and trading interfaces that stay accurate without hammering the server with requests.

## What Titan does

Titan's Argos routing engine acts as a meta-aggregator: it sources quotes from multiple DEX aggregators and RFQ (request-for-quote) providers simultaneously, then surfaces the best route to your client in real time.

When you connect to the Titan WebSocket endpoint and send a `NewSwapQuoteStream` request, Titan sends back a continuous stream of `SwapRoute` objects. Each route contains everything you need to execute the swap immediately — either a ready-to-sign transaction or a set of composable instructions.

### Key features

- **Real-time streaming** — WebSocket implementation delivers continuous quote updates without polling overhead.
- **Meta-aggregation** — Argos sources from multiple DEX aggregators and RFQ providers to minimize slippage and find the best available price.
- **Low latency** — Streaming quotes arrive faster than REST polling cycles, giving your application fresher data at lower cost.
- **DART re-optimization** — [Dynamically Allocated Real Time Routing (DART)](https://titan-exchange.gitbook.io/titan/developer-doc/dart-swap-api/overview) re-optimizes trades at the exact moment of execution, not just at quote time. This guarantees best execution even when market conditions shift between quote and submission.

### Use cases

- Trading interfaces that display live prices without constant HTTP requests
- Price monitoring dashboards
- Trading bots that need low-latency, always-fresh quote feeds
- Wallets with live swap pricing

## Getting started

<Warning>
Titan Swap API uses WebSocket connections. Use `wss://` in your endpoint URL, not `https://`.
</Warning>

Connect to Titan through your Triton endpoint using the WebSocket protocol:

```
wss://<endpoint>.rpcpool.com/<private_token>/titan
```

### Connecting with the TypeScript SDK

The official Titan TypeScript SDK handles connection management and message parsing for you:

```bash
npm install @titanexchange/sdk-ts
```

Once installed, initialize a client pointing at your Triton WebSocket endpoint and subscribe to a quote stream. Refer to the [Titan SDK documentation](https://www.npmjs.com/package/@titanexchange/sdk-ts) for the full API.

## Executing a swap

<Steps>
  <Step title="Connect to the WebSocket">
    Establish a WebSocket connection to your Triton Titan endpoint using `wss://`.
  </Step>
  <Step title="Request a quote stream">
    Send a `NewSwapQuoteStream` message with your swap parameters — input mint, output mint, amount, and slippage tolerance. Titan begins sending quote updates immediately.
  </Step>
  <Step title="Receive quote updates">
    Each message in the stream is a `SwapRoute` object containing the best route found across all aggregators and RFQ sources at that moment.
  </Step>
  <Step title="Select a quote">
    Choose the quote that meets your criteria — best output amount, preferred provider, lowest price impact, or any other factor relevant to your use case.
  </Step>
  <Step title="Execute the swap">
    Each `SwapRoute` contains either:
    - **Instructions** — composable transaction instructions you build and sign yourself
    - **Transaction** — a fully assembled, ready-to-sign transaction you can submit directly

    Sign with your wallet and send using your Triton Solana RPC endpoint.
  </Step>
</Steps>
