Metis is Jupiter's routing and quote engine, self-hosted on Triton One's infrastructure. It scans 20+ DEXes and AMMs across Solana's DeFi ecosystem, calculates optimal routes, splits trades when beneficial, and returns ready-to-sign swap transactions — all without requiring you to hold or stake any $JUP tokens.

## What Metis does

When you call the Metis quote endpoint, it evaluates liquidity across every major Solana DEX and AMM simultaneously, then constructs the most efficient route for your swap. If splitting across multiple pools gives a better price, Metis handles that automatically.

### Key features

- **Liquidity aggregation** — Combines liquidity from multiple AMMs and DEXes into a single optimal route.
- **Platform fees** — Pass a fee wallet and a `platformFeeBps` parameter in the quote request to collect fees directly in the swap flow.
- **ExactOut mode** — Specify the exact output amount you need to receive. Ideal for payment gateways that accept many tokens but settle in a single asset (e.g., USDC).
- **Circular arbitrage** — Triton enables circular routes such as USDC → token → USDC. This capability is disabled on Jupiter's public API by default.

### Use cases

- Wallets that need simple, reliable swap functionality
- Payment gateways that accept many input tokens and settle in one asset
- Trading bots and arbitrage systems, including circular arbitrage strategies
- DEX frontends with clean swap UIs

## Getting started

Your Metis endpoint follows this pattern:

```
https://<endpoint>.rpcpool.com/<private_token>/metis/quote
```

Replace `<endpoint>` with your Triton subdomain and `<private_token>` with your secret token from the [Customer Portal](https://customers.triton.one).

### Example quote request

The following request quotes a swap of 1 USDC (1,000,000 micro-lamports) into SOL with 0.5% slippage tolerance:

```bash
curl 'https://endpoint.rpcpool.com/private_token/metis/quote?\
inputMint=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v&\
outputMint=So11111111111111111111111111111111111111112&\
amount=1000000&\
slippageBps=50'
```

The response includes the best route, expected output amount, price impact, and the data needed to build the swap transaction.

## Executing a swap

<Steps>
  <Step title="Get a quote">
    Call the `/metis/quote` endpoint with your input mint, output mint, amount, and slippage tolerance. The response contains route and pricing information.

    ```bash
    curl 'https://endpoint.rpcpool.com/private_token/metis/quote?\
    inputMint=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v&\
    outputMint=So11111111111111111111111111111111111111112&\
    amount=1000000&\
    slippageBps=50'
    ```
  </Step>
  <Step title="Get swap instructions">
    Pass the quote response to the `/metis/swap` or `/metis/swap-instructions` endpoint to receive a ready-to-sign transaction or a set of composable instructions.
  </Step>
  <Step title="Sign and send">
    Sign the transaction with your wallet and submit it to the Solana network using your Triton RPC endpoint.
  </Step>
</Steps>

<Tip>
For complete details on the `/swap` and `/swap-instructions` endpoints, including all available parameters, see the [Metis API documentation](https://metis.builders/docs/get-quote).
</Tip>
