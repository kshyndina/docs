---

Accounts are the top-level billing entity in Triton One. Each account owns one or more subscriptions, and all charges are aggregated at the account level. You cannot create accounts via the API — account creation is handled by Triton administrators. If you need a new account provisioned (for example, to give a customer separate billing), contact Triton support. You can, however, list and retrieve accounts accessible to your token and update their billing details.

## List accounts

`GET /api/v1/accounts`

Returns all accounts that your authentication token has access to. Results are paginated.

### Query parameters

<ParamField query="name" type="string">
  Filter results to accounts whose name contains this value. No filter is applied by default.
</ParamField>

<ParamField query="per" type="integer" default="50">
  Maximum number of accounts to return per page.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number to return.
</ParamField>

### Request

<CodeGroup>

```bash All accounts
curl 'https://customers.triton.one/api/v1/accounts' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

```bash Filter by name
curl 'https://customers.triton.one/api/v1/accounts?name=Account-123' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

```bash Paginate results
curl 'https://customers.triton.one/api/v1/accounts?per=10&page=2' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

</CodeGroup>

### Response

Returns a `accounts` array and a `meta` object with pagination data.

<ResponseField name="accounts" type="object[]">
  Array of account objects.
</ResponseField>

<ResponseField name="meta" type="object">
  <Expandable title="properties">
    <ResponseField name="current_page" type="integer">Current page number.</ResponseField>
    <ResponseField name="next_page" type="integer | null">Next page number, or `null` if on the last page.</ResponseField>
    <ResponseField name="prev_page" type="integer | null">Previous page number, or `null` if on the first page.</ResponseField>
    <ResponseField name="per_page" type="integer">Number of results per page.</ResponseField>
    <ResponseField name="total_pages" type="integer">Total number of pages.</ResponseField>
    <ResponseField name="total_count" type="integer">Total number of accounts across all pages.</ResponseField>
  </Expandable>
</ResponseField>

```json
{
  "accounts": [
    { "...account_object_1..." },
    { "...account_object_2..." }
  ],
  "meta": {
    "current_page": 1,
    "next_page": null,
    "per_page": 50,
    "prev_page": null,
    "total_pages": 1,
    "total_count": 2
  }
}
```

## Get an account

`GET /api/v1/accounts/:account_uuid`

Returns the full details of a single account, including its subscriptions and any deactivation reasons.

### Path parameters

<ParamField path="account_uuid" type="string" required>
  UUID of the account to retrieve.
</ParamField>

### Request

```bash
curl 'https://customers.triton.one/api/v1/accounts/c92a9cea-47cc-494b-b1b0-4230a2316ee5' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

### Response

Returns an `account` object.

## Update an account

`PUT /api/v1/accounts/:account_uuid`

Update billing details on an account your token has access to.

### Path parameters

<ParamField path="account_uuid" type="string" required>
  UUID of the account to update.
</ParamField>

### Body parameters

Wrap all parameters inside an `account` key in your request body.

<ParamField body="name" type="string" required>
  Display name for the account.
</ParamField>

<ParamField body="billing_address1" type="string">
  First line of the billing address.
</ParamField>

<ParamField body="billing_address2" type="string">
  Second line of the billing address.
</ParamField>

<ParamField body="billing_address3" type="string">
  Third line of the billing address.
</ParamField>

<ParamField body="billing_city" type="string">
  Billing city.
</ParamField>

<ParamField body="billing_state_or_province" type="string">
  Billing state or province.
</ParamField>

<ParamField body="billing_postal_code" type="string">
  Billing postal code.
</ParamField>

<ParamField body="billing_country_code" type="string">
  ISO 3166-1 alpha-2 country code (e.g. `"US"`, `"GB"`).
</ParamField>

<ParamField body="telephone_country_code" type="string">
  Country dial code for the phone number.
</ParamField>

<ParamField body="telephone" type="string">
  Contact phone number.
</ParamField>

### Request

```bash
curl -X PUT 'https://customers.triton.one/api/v1/accounts/c6b8c375-27ab-4531-94f4-d8d08250fcfa' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "account": {
      "name": "John Doe",
      "billing_address1": "1645 S Telegraph Rd",
      "billing_address2": "line 2",
      "billing_address3": "line 3",
      "billing_city": "Bloomfield Hills",
      "billing_state_or_province": "Michigan",
      "billing_postal_code": "48302",
      "billing_country_code": "US",
      "telephone_country_code": "US",
      "telephone": "(248) 858-2300"
    }
  }'
```

### Response

Returns the updated `account` object in the same shape as `GET /api/v1/accounts/:account_uuid`.

<Note>
  Account creation is restricted to Triton administrators and is not available through the API. Contact [support@triton.one](mailto:support@triton.one) to request a new account.
</Note>
