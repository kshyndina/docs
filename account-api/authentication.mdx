Every request to the Account Management API must include an `Authorization` header containing your API token. Tokens are scoped to the role assigned to them (Operator or Reseller), so only the operations permitted for your role will succeed. You generate tokens in the [Customer Portal](https://customers.triton.one) once Triton grants you the appropriate access level.

## Required headers

All endpoints consume and produce JSON. You must send all three headers on every request.

<ParamField header="Authorization" type="string" required>
  Your Account Management API token. Pass the raw token value — no `Bearer` prefix required.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json` for any request with a body.
</ParamField>

<ParamField header="Accept" type="string" required>
  Must be `application/json` so the API returns JSON responses.
</ParamField>

## Verifying your token

The fastest way to verify your token is working is to call `GET /api/v1/accounts`. A `200 OK` response means your token is valid and correctly scoped. Any other status indicates an authentication or authorization problem.

```bash
curl -H "Authorization: secret" \
     -H "Content-Type: application/json" \
     -H "Accept: application/json" \
     https://customers.triton.one/api/v1/accounts
```

A successful response returns an `accounts` array and pagination metadata:

```json
{
  "accounts": [ ... ],
  "meta": {
    "current_page": 1,
    "next_page": null,
    "per_page": 50,
    "prev_page": null,
    "total_pages": 1,
    "total_count": 1
  }
}
```

## Getting access

If you do not yet have an Account Management API token, contact Triton at [support@triton.one](mailto:support@triton.one) or through your dedicated support channel. You will need to request either the **Operator** or **Reseller** role depending on what operations you intend to perform.

<Warning>
  This token is only for the Account Management API at `customers.triton.one/api`. It does not grant access to any Solana RPC endpoint. RPC access tokens are distinct credentials that you create and manage through this API — see [Tokens](/account-api/tokens).
</Warning>

<Tip>
  The examples throughout this guide use `curl`, but you can use any HTTP client or library. The only requirement is that you attach the three required headers to each request.
</Tip>
