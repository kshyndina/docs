---
title: "Address Watch Lists: Monitor On-Chain Addresses"
sidebarTitle: "Watch Lists"
description: "Create and manage on-chain address watch lists scoped to a Triton One subscription to monitor and apply special handling to specific addresses."
---

Address watch lists let you register on-chain addresses against a subscription so that Triton's infrastructure can apply special handling or monitoring to activity involving those addresses. Each watch list entry is scoped to a subscription and classified by variant — either `collection` (a flat set of addresses) or `tree` (a hierarchical structure). This feature must be enabled on your account; contact [support@triton.one](mailto:support@triton.one) if you need access.

All address watch list endpoints require an **Operator** or **Reseller** role token.

<Note>
  Check that `address_watch_lists` is `true` on your account before calling these endpoints. If it is `false`, contact Triton support to have the feature enabled.
</Note>

---

## Add a watch list

`POST /api/v1/subscriptions/:subscription_uuid/address_watch_lists`

Creates a new address watch list entry on the given subscription.

### Path parameters

<ParamField path="subscription_uuid" type="string" required>
  UUID of the subscription to attach the watch list entry to.
</ParamField>

### Body parameters

<ParamField body="variant" type="string" required>
  The type of watch list structure. Must be either `collection` or `tree`.
</ParamField>

<ParamField body="encoded_value" type="string" required>
  The encoded address or address structure to watch. The exact encoding format depends on the `variant` you choose.
</ParamField>

### Request

```bash
curl -X POST 'https://customers.triton.one/api/v1/subscriptions/74ea9d9a-4b2a-4f01-af47-1c175f8a2af6/address_watch_lists' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "variant": "collection",
    "encoded_value": "<base58-encoded-address>"
  }'
```

### Response

Returns the created watch list object, including its UUID for use in delete operations.

## List watch lists

`GET /api/v1/address_watch_lists`

Returns all watch list entries accessible to your token. Filter results by variant, subscription, or subscription type.

### Query parameters

<ParamField query="variant" type="string">
  Filter by variant: `collection` or `tree`.
</ParamField>

<ParamField query="subscription_uuid" type="string">
  Filter results to watch lists on a specific subscription.
</ParamField>

<ParamField query="subscription_type" type="string">
  Filter results to watch lists on subscriptions of a given type (e.g. `mainnet-shared`).
</ParamField>

### Request

<CodeGroup>

```bash All watch lists
curl 'https://customers.triton.one/api/v1/address_watch_lists' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

```bash Filter by subscription
curl 'https://customers.triton.one/api/v1/address_watch_lists?subscription_uuid=74ea9d9a-4b2a-4f01-af47-1c175f8a2af6' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

```bash Filter by variant
curl 'https://customers.triton.one/api/v1/address_watch_lists?variant=collection' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

</CodeGroup>

### Response

Returns an `address_watch_lists` array of watch list objects, each including its `uuid`, `variant`, `encoded_value`, and the subscription it belongs to.

## Delete a watch list

`DELETE /api/v1/address_watch_lists/:uuid`

Removes a watch list entry. This action is permanent.

### Path parameters

<ParamField path="uuid" type="string" required>
  UUID of the watch list entry to delete.
</ParamField>

### Request

```bash
curl -X DELETE 'https://customers.triton.one/api/v1/address_watch_lists/b4d5ec62-410d-45f8-8b45-44fe6641cf1f' \
  -H "Authorization: secret-api-token" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json"
```

### Response

```
204 No Content
```

<Warning>
  Deleting a watch list entry cannot be undone. If you need to restore it, you must re-add it with a new POST request.
</Warning>
