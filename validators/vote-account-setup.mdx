Before your hosted validator can participate in consensus, you need to set up a vote account and provide Triton with the necessary keys. This page explains the three types of keys involved and how to create the ones you are responsible for.

<Note>
  If Triton is hosting your validator, we will set up the vote account on your behalf as part of the onboarding process. The instructions below are provided for transparency and educational purposes.
</Note>

## Keys required for a validator

A Solana validator requires three distinct keys:

| Key | Who holds it | Purpose |
| --- | ------------ | ------- |
| Node identity key pair | Triton | Signs votes on behalf of your vote account; must maintain a SOL balance to pay vote fees |
| Vote account key pair | You (public key only needed after setup) | Identifies your vote account on-chain |
| Withdrawal key pair | You | Controls the vote account; used to withdraw rewards and change commission |

## Node identity key pair

Triton owns and holds the node identity key pair. You are responsible for maintaining a minimum balance of **10 SOL** on the node identity account. If the balance drops below this threshold, the validator will stop functioning — contact Triton support if you need the node identity's public key to top it up directly.

The node identity also accrues rewards that help offset vote fees over time. Depending on the stake your validator attracts, these rewards may partially or fully cover your vote transaction costs.

## Create your withdrawal key pair

The withdrawal key pair controls the vote account. Anyone with this key can withdraw accumulated rewards, change the validator's commission rate, or update the vote account's authorized voter. **Keep it safe.**

<Warning>
  Never store the withdrawal key pair in a hot wallet or an online wallet service. Use a hardware wallet or cold storage. Losing access to this key pair means losing control of your vote account and any accumulated rewards.
</Warning>

Generate the withdrawal key pair with the Solana CLI:

```bash
solana-keygen new -o ~/authorized-withdrawer-keypair.json
```

Store the resulting file and its seed phrase securely offline.

## Create your vote account

Once you have your withdrawal key pair and Triton has provided the node identity public key, create your vote account:

<Steps>
  <Step title="Generate a vote account key pair">
    ```bash
    solana-keygen new -o ~/vote-account-keypair.json
    ```

    After the vote account is created, only the public key of this file matters. The vote account itself is controlled by the withdrawal key pair you created above.
  </Step>

  <Step title="Create the vote account on-chain">
    Replace `<pubkey for node identity>` with the public key provided by Triton:

    ```bash
    solana create-vote-account \
      ~/vote-account-keypair.json \
      <pubkey for node identity> \
      ~/authorized-withdrawer-keypair.json
    ```

    This transaction registers the vote account on the Solana network, links it to the node identity, and sets the withdrawal authority to your withdrawal key pair.
  </Step>
</Steps>
