## What to include

The more you give us up front, the faster we can help. Bare minimum:

| For | Include |
|---|---|
| **Any RPC issue** | Endpoint URL (without the token), method name, timestamp (UTC), and a sample request + response. The Logs tab in the portal exports this directly. |
| **Performance / latency** | The above plus: client region, observed latency, target latency, traffic profile (RPS, method mix). |
| **Streaming issue (gRPC, WS)** | Subscription filter, observed message rate vs expected, any client-side errors, network capacity (bandwidth + RTT to our region). |
| **Billing / invoice** | Invoice number, payment method, expected vs actual amount. |
| **Security / leaked token** | Token prefix (first 8 chars), the channel where the leak surfaced, current state (revoked? still active?). |

## Severity levels

We classify support requests by severity so the right person responds first.

| Severity | Definition | Response target |
|---|---|---|
| **Sev 1** | Production down, no workaround | `<30 min`, 24/7 (committed and above) |
| **Sev 2** | Production degraded or major feature broken | `<2 hours` business hours |
| **Sev 3** | Question, feature request, non-blocking issue | `<1 business day` |
| **Sev 4** | Documentation feedback, suggestions | Best-effort |

## Status page and incidents

Live infrastructure status is at [status.triton.one](https://status.triton.one). Subscribe to the RSS feed or webhook for real-time updates. Active incidents are posted there before they get to email.

If you're seeing something that doesn't show up on status.triton.one but you suspect is on our side, **open a Sev 1 ticket and reference the symptom precisely** (timestamp, endpoint, error). We'll investigate and update the status page if confirmed.

## What we can't help with

- **Solana validator-network issues** that are network-wide (e.g. consensus halts). Watch [status.solana.com](https://status.solana.com) and the Solana Foundation's channels.
- **Smart-contract debugging** -- we route the call, we don't write your program. Try [Solana Stack Exchange](https://solana.stackexchange.com).
- **Wallet support** -- contact Phantom, Solflare, etc. directly.

## Hours

Engineering support is staffed 24/7 for Sev 1 issues on committed and dedicated plans. PAYG support is business-hours; for production traffic on PAYG, we recommend upgrading to committed for the SLA.

Time zones: support team is split across Europe, North America, and Asia-Pacific.
