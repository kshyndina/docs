## Roles and where to do common things

Your customer dashboard has three roles: **Admin**, **Standard**, and **Operator**. New members default to **Standard**, which gives read access plus a few self-serve actions. Promote to **Operator** when someone needs to modify endpoints, rotate tokens, manage allowlists, or invite teammates. **Admin** is reserved for the organisation owner -- contact support to transfer or add one.

The table below shows where each role goes for the common tasks. When both roles do the same thing, the column is merged. When they differ, Standard goes through support and Operator has a direct path.

## Per-endpoint pages

Each endpoint has six tabs:

1. **Overview** -- region, infrastructure type, status, recent uptime.
2. **Auth** -- tokens and allowlists.
3. **Usage** -- per-method counts, error rate, cost.
4. **Methods** -- which JSON-RPC and gRPC methods are enabled / cost-multiplied.
5. **Limits** -- rate, concurrency, per-method overrides (configurable on dedicated; read-only on shared by default -- support can tune).
6. **Logs** -- recent requests with timestamp, method, status, and latency. Useful for debugging 429s and unusual responses.
