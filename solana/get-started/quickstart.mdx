## Get your first request working

<Steps>
  <Step title="Set up your account">
    Sign up at [customers.triton.one](https://customers.triton.one/users/sign-up), verify your email, top up the $125 minimum (card, USDC, hel.io or wire). Full walkthrough: [Set up your account and add users](/solana/get-started/account-management/set-up-your-account-and-add-users).
  </Step>

  <Step title="Provision an endpoint">
    Open the dashboard, click **Create endpoint**, pick **Solana mainnet** (or devnet for testing), and choose the closest region. The portal returns two things you'll use everywhere:

    - **Endpoint URL** — `<your-endpoint>.mainnet.rpcpool.com`
    - **Secret token** — a long random string

    Keep the token server-side only. Frontend code uses an origin allowlist instead. See [Auth and security](/solana/get-started/account-management/auth-and-security-best-practices).
  </Step>

  <Step title="Send your first request">
    Call `getSlot` to confirm the endpoint is live. Pick your stack:

    <CodeGroup>

    ```bash curl
    curl https://<endpoint>.mainnet.rpcpool.com/<token> \
      -H "Content-Type: application/json" \
      -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
    ```

    ```javascript Solana Kit
    import { createSolanaRpc } from "@solana/kit";

    const rpc = createSolanaRpc("https://<endpoint>.mainnet.rpcpool.com/<token>");
    const slot = await rpc.getSlot().send();
    console.log(slot);
    ```

    ```javascript web3.js
    import { Connection } from '@solana/web3.js';

    const conn = new Connection(
      'https://<endpoint>.mainnet.rpcpool.com/<token>',
      'confirmed'
    );
    console.log(await conn.getSlot());
    ```

    ```python python
    import requests

    r = requests.post(
        'https://<endpoint>.mainnet.rpcpool.com/<token>',
        json={'jsonrpc': '2.0', 'id': 1, 'method': 'getSlot'},
    )
    print(r.json()['result'])
    ```

    ```rust rust
    use solana_client::rpc_client::RpcClient;

    let client = RpcClient::new(
        "https://<endpoint>.mainnet.rpcpool.com/<token>".to_string(),
    );
    println!("{}", client.get_slot()?);
    ```

    </CodeGroup>

    Expected response:

    ```json
    { "jsonrpc": "2.0", "result": 311340987, "id": 1 }
    ```

    <Check>
      You're connected. The slot ticks every ~400ms; run it again and the number changes.
    </Check>
  </Step>
</Steps>

## Connection pooling for web3.js (Node.js)

If you're using `@solana/web3.js` from Node.js for any meaningful traffic, configure connection pooling at app startup. Without this, the default `undici` client exhausts ephemeral ports under concurrency. This applies to every Solana RPC provider, not just Triton.

```javascript
import { setGlobalDispatcher, Agent } from 'undici';

setGlobalDispatcher(new Agent({
  connections: 50,
  pipelining: 1,
  keepAliveTimeout: 60_000,
  keepAliveMaxTimeout: 300_000,
}));
```

## Common first-call issues

<AccordionGroup>
  <Accordion title="401 Unauthorized" icon="lock">
    The token is wrong, or you're calling a public endpoint from an origin not on its allowlist. Re-check the token in the portal under your endpoint's **Auth** tab, or add your origin (e.g. `https://yourapp.com`) to the allowlist.
  </Accordion>
  <Accordion title="429 Too Many Requests" icon="gauge">
    You've hit the rate limit on the endpoint or the calling IP. Pause for 10 seconds, then resume. See [Rate and connection limits](/solana/get-started/rate-and-connection-limits) for the full numbers.
  </Accordion>
  <Accordion title="Connection timeout from a browser" icon="globe">
    Public endpoints require an origin allowlist. Open **Auth** in the portal, add the origin you're calling from, save, and retry.
  </Accordion>
  <Accordion title="403 on gRPC" icon="shield-x">
    Token must be passed as `x-token` metadata, not in the URL path. See [Auth and security](/solana/get-started/account-management/auth-and-security-best-practices) for the exact pattern.
  </Accordion>
</AccordionGroup>
