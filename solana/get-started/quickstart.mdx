## Get your first request working

<Steps>
  <Step title="Sign up and deposit $125" titleSize="h3">
    Sign up at [customers.triton.one](https://customers.triton.one/users/sign-up), verify your email, top up the $125 minimum (card, USDC, hel.io or wire).
  </Step>

  <Step title="Set up an endpoint" titleSize="h3">
    Open the dashboard, click **Create endpoint**, pick **Solana mainnet** (or devnet for testing), and choose the closest region. The portal returns two things you'll use everywhere:

    - **Endpoint URL**: `<your-endpoint>.mainnet.rpcpool.com`
    - **Secret token**: a long random string

    Keep the token server-side only. Frontend code uses an origin allowlist instead. See [Auth and security](/solana/get-started/account-management/auth-and-security-best-practices).

    Full walkthrough: [Set up your account and add users](/solana/get-started/account-management/set-up-your-account-and-add-users).
  </Step>

  <Step title="Send your first request" titleSize="h3">
    Call `getSlot` to confirm the endpoint is live. Pick your stack:

    <CodeGroup>

    ```bash curl
    curl https://<endpoint>.mainnet.rpcpool.com/<token> \
      -H "Content-Type: application/json" \
      -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
    ```

    ```javascript Solana Kit
    import { createSolanaRpc } from "@solana/kit";

    const rpc = createSolanaRpc("https://<endpoint>.mainnet.rpcpool.com/<token>");
    const slot = await rpc.getSlot().send();
    console.log(slot);
    ```

    ```javascript web3.js
    import { Connection } from '@solana/web3.js';

    const conn = new Connection(
      'https://<endpoint>.mainnet.rpcpool.com/<token>',
      'confirmed'
    );
    console.log(await conn.getSlot());
    ```

    ```python python
    import requests

    r = requests.post(
        'https://<endpoint>.mainnet.rpcpool.com/<token>',
        json={'jsonrpc': '2.0', 'id': 1, 'method': 'getSlot'},
    )
    print(r.json()['result'])
    ```

    ```rust rust
    use solana_client::rpc_client::RpcClient;

    let client = RpcClient::new(
        "https://<endpoint>.mainnet.rpcpool.com/<token>".to_string(),
    );
    println!("{}", client.get_slot()?);
    ```

    </CodeGroup>

    Expected response:

    ```json
    { "jsonrpc": "2.0", "result": 311340987, "id": 1 }
    ```

    <Note>
      You should be connected. If something doesn't work (401, 429, timeouts, gRPC 403), see the [Error handling guide](/solana-guides/error-handling/overview) for the full debug flow.
    </Note>
  </Step>
</Steps>

## Where to next

You have an endpoint and a working call. Two ways to navigate from here.

<Tabs>
  <Tab title="By product (I know what I want)">
    Each Triton product handles one job. Pick the one that matches what you're building.

    ### Reading state

    <CardGroup cols={2}>
      <Card title="Standard RPC" icon="zap" href="/solana/reading-state/standard-rpc">
        Solana JSON-RPC over HTTPS. All standard methods. Default for most apps.
      </Card>
      <Card title="Steamboat" icon="database" href="/solana/streaming/steamboat/overview">
        Custom indexes built from your gRPC stream. 50x faster than `getProgramAccounts`.
      </Card>
      <Card title="DAS API" icon="image" href="/solana/digital-assets/das-api/overview">
        Unified read for NFTs, cNFTs, SPL, Token-2022. One method per common query.
      </Card>
      <Card title="Account Sync" icon="refresh-cw" href="/solana/reading-state/account-sync">
        Live account-state mirror, Geyser-fed. No polling, always current.
      </Card>
    </CardGroup>

    ### Streaming

    <CardGroup cols={2}>
      <Card title="Dragon's Mouth gRPC" icon="zap" href="/solana/streaming/dragons-mouth/overview">
        Sub-slot account, transaction, slot and block subscriptions over gRPC.
      </Card>
      <Card title="Whirligig" icon="radio" href="/solana/streaming/whirligig/overview">
        Drop-in replacement for native Solana WebSockets. Custom `transactionSubscribe`.
      </Card>

        Multi-node merge, persistent storage, resume from cursor. Use when you can't lose events.
      </Card>

        Pyth price feed API. REST plus WebSocket. Powers Pyth JS SDK.
