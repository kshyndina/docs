Five minutes from "I want a Solana endpoint" to "my first `getSlot` call works".

## Before you start

You need:

- A signed-up [Triton account](https://customers.triton.one/users/sign-up).
- A **$125 prepaid deposit** (the minimum, valid for up to one year). The deposit replaces a free trial; it gives you a real production-grade endpoint immediately.
- A terminal with `curl`, or your language runtime of choice.

## Sign up and provision your endpoint

The signup flow at [customers.triton.one](https://customers.triton.one) walks you through deposit and endpoint creation in one go.

<Steps>
  <Step title="Sign up">
    Sign up at [customers.triton.one](https://customers.triton.one/users/sign-up) with your email. You'll verify by clicking the link we send you.
  </Step>
  <Step title="Deposit $125">
    Pick a payment method (card via Coinflow, USDC, hel.io, or wire). The minimum deposit is $125 and it stays valid for up to one year. Top-ups can be any amount once you're set up.
  </Step>
  <Step title="Pick your endpoint">
    Choose **Solana mainnet** (or devnet for testing), pick the closest region, and the portal provisions instantly. You'll land on the endpoint's page with two things you need:
    - **Endpoint URL** in the form `<your-endpoint>.mainnet.rpcpool.com`
    - **Secret token** -- a long random string

    <Info>
    Standard users can't create new endpoints or tokens themselves -- those actions are admin-only. If you're joining an existing organisation, ask the admin to create the endpoint and share access. If you're the first signup, you're automatically the owner.
    </Info>
  </Step>
  <Step title="Pick the right URL pattern for where your code runs">
    Triton has three canonical URL patterns. Use the one matching your code:

    | Where | URL pattern | Auth |
    |---|---|---|
    | **Frontend (browser)** | `https://<endpoint>.mainnet.rpcpool.com` (no token) | Origin allowlist set in portal |
    | **Backend (Rust, Go, Node, Python)** | `https://<endpoint>.mainnet.rpcpool.com/<token>` | Token in URL path |
    | **gRPC streaming** | `<endpoint>.mainnet.rpcpool.com:443` + `x-token` metadata | Token in `x-token` gRPC metadata |

    Never put a token in frontend code -- it's visible to anyone with devtools. See [Auth and security](/solana/get-started/account-management/auth-and-security-best-practices) for the full pattern.
  </Step>
</Steps>

## Send your first request

Call `getSlot`. It returns the current Solana slot number and confirms the endpoint is live.

<CodeGroup>

```bash curl
curl https://<endpoint>.mainnet.rpcpool.com/<token> \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
```

```javascript node-fetch
const ENDPOINT = 'https://<endpoint>.mainnet.rpcpool.com/<token>';

const res = await fetch(ENDPOINT, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ jsonrpc: '2.0', id: 1, method: 'getSlot' })
});
console.log((await res.json()).result);
```

```javascript web3.js
import { Connection } from '@solana/web3.js';

const connection = new Connection(
  'https://<endpoint>.mainnet.rpcpool.com/<token>',
  'confirmed'
);
console.log(await connection.getSlot());
```

```python python
import requests

ENDPOINT = 'https://<endpoint>.mainnet.rpcpool.com/<token>'

r = requests.post(ENDPOINT, json={
    'jsonrpc': '2.0', 'id': 1, 'method': 'getSlot'
})
print(r.json()['result'])
```

```rust rust
use solana_client::rpc_client::RpcClient;

let client = RpcClient::new(
    "https://<endpoint>.mainnet.rpcpool.com/<token>".to_string()
);
println!("{}", client.get_slot()?);
```

</CodeGroup>

```json
{ "jsonrpc": "2.0", "result": 311340987, "id": 1 }
```

<Check>
You're connected. Slot ticks every ~400ms; run again and the number changes.
</Check>

## Connection pooling for web3.js (Node.js)

If you use `@solana/web3.js` from Node.js for any meaningful traffic, configure connection pooling at app startup. Without this, the default `undici` client exhausts ephemeral ports under concurrency. This applies to every Solana RPC provider, not just Triton.

```javascript
import { setGlobalDispatcher, Agent } from 'undici';

setGlobalDispatcher(new Agent({
  connections: 50,
  pipelining: 1,
  keepAliveTimeout: 60_000,
  keepAliveMaxTimeout: 300_000,
}));
```

## Common first-call issues

<AccordionGroup>
  <Accordion title="401 Unauthorized" icon="lock">
    The token is wrong, or you're calling a public endpoint from an origin not on its allowlist. Re-check the token in the portal under your endpoint's **Auth** tab, or add your origin (e.g. `https://yourapp.com`) to the allowlist.
  </Accordion>
  <Accordion title="429 Too Many Requests" icon="gauge">
    You've hit the rate limit on the endpoint or the calling IP. Pause for 10 seconds, then resume. See [Rate and connection limits](/solana/get-started/rate-and-connection-limits) for the full numbers.
  </Accordion>
  <Accordion title="Connection timeout from a browser" icon="globe">
    Public endpoints require an origin allowlist. Open **Auth** in the portal, add the origin you're calling from, save, and retry.
  </Accordion>
</AccordionGroup>
