Five minutes from sign-up to your first request. Then a routed path to whichever product or use case fits your build.

## Get your first request working

<Steps>
  <Step title="Set up your account">
    Sign up at [customers.triton.one](https://customers.triton.one/users/sign-up), verify your email, top up the $125 minimum (card, USDC, hel.io or wire). Full walkthrough: [Set up your account and add users](/solana/get-started/account-management/set-up-your-account-and-add-users).
  </Step>

  <Step title="Provision an endpoint">
    Open the dashboard, click **Create endpoint**, pick **Solana mainnet** (or devnet for testing), and choose the closest region. The portal returns two things you'll use everywhere:

    - **Endpoint URL** — `<your-endpoint>.mainnet.rpcpool.com`
    - **Secret token** — a long random string

    Keep the token server-side only. Frontend code uses an origin allowlist instead. See [Auth and security](/solana/get-started/account-management/auth-and-security-best-practices).
  </Step>

  <Step title="Send your first request">
    Call `getSlot` to confirm the endpoint is live. Pick your stack:

    <CodeGroup>

    ```bash curl
    curl https://<endpoint>.mainnet.rpcpool.com/<token> \
      -H "Content-Type: application/json" \
      -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
    ```

    ```javascript Solana Kit
    import { createSolanaRpc } from "@solana/kit";

    const rpc = createSolanaRpc("https://<endpoint>.mainnet.rpcpool.com/<token>");
    const slot = await rpc.getSlot().send();
    console.log(slot);
    ```

    ```javascript web3.js
    import { Connection } from '@solana/web3.js';

    const conn = new Connection(
      'https://<endpoint>.mainnet.rpcpool.com/<token>',
      'confirmed'
    );
    console.log(await conn.getSlot());
    ```

    ```python python
    import requests

    r = requests.post(
        'https://<endpoint>.mainnet.rpcpool.com/<token>',
        json={'jsonrpc': '2.0', 'id': 1, 'method': 'getSlot'},
    )
    print(r.json()['result'])
    ```

    ```rust rust
    use solana_client::rpc_client::RpcClient;

    let client = RpcClient::new(
        "https://<endpoint>.mainnet.rpcpool.com/<token>".to_string(),
    );
    println!("{}", client.get_slot()?);
    ```

    </CodeGroup>

    Expected response:

    ```json
    { "jsonrpc": "2.0", "result": 311340987, "id": 1 }
    ```

    <Note>
      You should be connected. If something doesn't work — 401, 429, timeouts, gRPC 403 — see the [Error handling guide](/solana-guides/error-handling) for the full debug flow.
    </Note>
  </Step>
</Steps>
