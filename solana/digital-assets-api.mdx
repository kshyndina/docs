The Digital Assets API (DAS API) gives you a fast, indexed way to query any digital asset on Solana — regular NFTs, compressed NFTs, SPL tokens, and Token-2022 (Token Extensions) — through a single, consistent JSON-RPC interface. Triton One actively contributes to the Metaplex DAS standard and runs a production-grade indexing and caching layer behind all its endpoints. Compressed NFT decompression and metadata caching happen server-side, so you get clean, structured responses without any extra work.

## How to use it

The DAS API is enabled by default on every shared and dedicated Triton One endpoint — no separate signup, no code changes, and no different endpoint URL. Any `getAsset`, `searchAssets`, or other DAS method you send to your standard Solana mainnet endpoint is automatically routed to the indexer.

<Note>
  DAS API calls are billed at **$50 per million requests**. Standard rate limits for your RPC plan apply. Check your account panel at [customers.triton.one](https://customers.triton.one) for detailed billing information.
</Note>

All requests follow the JSON-RPC 2.0 spec:

```bash
curl -X POST https://your-endpoint.mainnet.rpcpool.com/your-token \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "getAsset",
    "params": {
      "id": "EKpQLNFP6DQ2YiXrD5f2eRkNfxFnrQWpxdLHa7xGmN3x"
    }
  }'
```

## Fungible tokens

The DAS API indexes all mints and token accounts for both the original SPL Token Program and the Token Extensions Program (Token-2022). You can query token balances, metadata, and program details through the same interface you use for NFTs.

To retrieve all tokens held by a wallet — SPL, Token-2022, regular NFTs, and compressed NFTs — use `searchAssets` with `tokenType: "All"`:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "searchAssets",
  "params": {
    "ownerAddress": "5aZZ4duJUKiMsJN9vRsoAn4SDX7agvKu7Q3QdFWRfWze",
    "tokenType": "All"
  }
}
```

The response for fungible assets includes a `token_info` block with balance, supply, decimals, and the associated token address. Token-2022 assets additionally include a `mint_extensions` field when applicable:

```json
{
  "mint_extensions": {
    "transfer_fee_config": {
      "withheld_amount": 0,
      "newer_transfer_fee": {
        "epoch": 500,
        "maximum_fee": 1000000000,
        "transfer_fee_basis_points": 500
      },
      "withdraw_withheld_authority": "AuthorityPublicKey",
      "transfer_fee_config_authority": "AuthorityPublicKey"
    }
  }
}
```

## Compressed NFTs and Merkle proofs

When you query a compressed NFT through `getAsset`, the response includes a `compression` field indicating the asset's tree address, leaf index, and current data hash. To make changes to a compressed asset (transfers, burns, etc.), you need the Merkle proof path. Use `getAssetProof` with the asset's public key to retrieve it.

The proof is required when constructing the transaction instruction that calls the Bubblegum program to verify the asset's position in the concurrent Merkle tree.
