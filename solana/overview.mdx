Triton One gives you complete access to the Solana network through standard JSON-RPC and WebSocket APIs, with full coverage of mainnet, testnet, and devnet. Beyond compatibility with any existing Solana SDK, every endpoint also ships with the full historical archive, real-time gRPC data streams, and a set of enhanced APIs that most providers don't offer at all.

## Core RPC

Every Triton One endpoint is fully compatible with the Solana JSON-RPC and WebSocket specifications. Whether you're using `@solana/web3.js`, the Rust SDK, or making raw HTTP calls, your existing code works without modification. Mainnet, testnet, and devnet are all available.

All endpoints provide access to the complete Solana ledger back to genesis. When you call `getBlock` or `getTransaction` for old data, routing to the historical archive happens automatically — you don't need a separate endpoint or any extra configuration.

## Project Yellowstone

Project Yellowstone is Triton One's suite of infrastructure improvements that go beyond standard Solana RPC. Key components include:

- **Dragon's Mouth gRPC subscriptions** — low-latency real-time streams for accounts, slots, transactions, and blocks
- **Whirligig WebSockets** — highly reliable WebSocket subscriptions with improved reconnection handling
- **Steamboat custom indexes** — dramatically faster `getProgramAccounts` for your specific query patterns
- **Old Faithful archive** — the open-source, community-owned historical ledger solution
- **Yellowstone Shield** — on-chain MEV protection policies
